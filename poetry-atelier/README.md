# 명도재 시창작소 — 공개형 정적 웹앱 시범판

- index.html: 전시 및 운영 웹앱
- works.json: 4편의 시 및 AI 시평, 20인 연구 자료
- PNG 3종: 16:9 펜화/수채화/일러스트
- MP4 4종: 32초 시화 정지 이미지 영상. 자체 제작 배경음 AAC 포함. **음성 시낭송은 미포함**
- original_instrumental.wav: 자체 생성 배경음

## 한계
원시 전문 미확보로 소재 기반 재창작. 실제 시인의 창작·감수 아님. 사이트 자동 AI 시 생성과 서버형 중앙저장소는 미구현. 브라우저 localStorage 및 JSON 내보내기/가져오기로 작품 관리 시범 구현.

## 배포
정적 파일을 공개 웹호스팅에 업로드. 공개 발행에는 저작권/실명/동의/비용/스토리지 검토 필요.
