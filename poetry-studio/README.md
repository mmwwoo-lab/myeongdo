# 명도재 스테인드글라스 음악 시화 스튜디오

시 제목, 시인 이름과 원문을 하나의 입력창에 넣어 **16:9(1280×720) 스테인드글라스 미디어아트**를 생성하는 웹앱입니다.

- `index.html`: 독립 실행 웹앱(프로덕션 경로)
- `source/index.html`: 동일한 편집용 HTML
- `source/app.js`: 최신 음악 영상 로직(참고용 추출 소스)

## 기능

1. 단일 입력창: 첫 줄 제목, 둘째 줄 이름, 그다음 시 내용
2. 시어 분석: 계절·정서·상징 소재별 다층 스테인드글라스 묘사
3. 브라우저 합성 배경음악: 피아노·플루트·현악
4. 시간 설정형 시 자막 스크롤과 강조 표시
5. 16:9 PNG 저장 및 음악 포함 영상 저장(MP4 지원 시 MP4, 아니면 WebM)

**음성 낭송과 낭송 관련 UI, 마이크, TTS는 포함하지 않습니다.** 영상 오디오에는 배경음악만 들어갑니다. MP4 오디오 코덱은 브라우저에 따라 Opus일 수 있으므로, 모든 재생기 호환성을 보장하지 않습니다. 영상은 실제 재생 시간만큼 실시간으로 녹화되며 종료 후 다운로드됩니다.

## 실행

최신 Chrome 또는 Edge에서 `index.html`을 열어 사용합니다. 오디오 재생 및 영상 녹화는 사용자가 버튼을 눌러 시작합니다.
