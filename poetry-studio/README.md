# 명도재 시화·작곡·낭송 스튜디오 v1

기존 **아나운서 톤 시낭송 & 수채화 시화 시어터**를 기반으로 시 입력 → 시어 분석 → 16:9 수채화 시화 → 정서 기반 기악 작곡 → 스크롤 시낭송 → 영상 내보내기를 재작성한 웹 앱입니다.

## 설치 없이 바로 열기 (기본 모드)

`명도재_시화스튜디오_단독실행.html`을 Chrome/Edge에서 열면 서버 없이 기본 시화·음악·브라우저 낭송 및 파일 음성 활용·녹화를 사용할 수 있습니다. 웹에서 가져오는 AI 시화·AI 음성 버튼은 이 모드에서 동작하지 않습니다. 일부 브라우저는 로컬 파일의 마이크 사용을 차단할 수 있습니다.

## 실행 (Windows/macOS)

Node.js 20 이상이 설치되어 있어야 합니다. Windows에서는 `start_windows.bat`을 더블클릭해도 됩니다. 압축 파일을 풀고 그 폴더에서:

```bash
npm start
```

Chrome 또는 Edge에서 **http://127.0.0.1:4173**으로 접속합니다. `npm install`은 필요하지 않습니다.

1. 시 제목·작가·본문을 입력하고 **시 분석 · 시화와 음악 기획**을 누릅니다.
2. **수채화 시화 그리기**를 누르면 시의 계절과 소재가 반영된 1280×720 그림을 만듭니다. 또는 **AI 고급 시화 생성**(키 필요), 사용자 이미지 업로드를 사용합니다.
3. **시에 맞춰 작곡**을 누릅니다. 정서에 따라 66~88 BPM의 장조/단조, 4화음 순환, 피아노·현악·플루트 선율이 만들어집니다. **영상 감상**에서 연주를 들을 수 있습니다.
4. **영상 감상**은 여성 한국어 브라우저 TTS(존재할 때)를 시의 행마다 읽고, 스크롤과 음악 덕킹을 함께 실행합니다. 여성 음성 보장이 안 되는 OS에선 한국어 기본 음성을 사용합니다.
5. **음성까지 들어간 WebM 영상**을 제작하려면 먼저 `AI 여성 낭송 만들기`, `낭송 MP3·WAV 선택`, `마이크 낭송 녹음` 중 하나로 **녹음 가능한 낭송 음원**을 확보한 후 **음성 포함 영상 녹화**를 누르세요. 녹화는 시와 함께 실시간 진행되며 종료 후 WebM을 다운로드합니다. MP4가 필요하면 편집기/FFmpeg 등으로 변환할 수 있습니다.
6. 이미지 PNG(시 원문 제외), 30초 작곡 음악 WAV, 프로젝트 JSON(바이너리 파일 제외)을 저장할 수 있습니다.

### 환경변수 (선택)

기본 시화·작곡·브라우저 TTS·마이크 낭송·음성 파일 포함 녹화는 **API 키 없이 작동**합니다. 고급 이미지/AI 음성을 사용하려면 `.env.example`을 `.env`로 복사하고 `OPENAI_API_KEY=...`을 설정한 뒤 서버를 재시작합니다. `.env`는 Git 저장소에 올리지 마세요.

```ini
OPENAI_API_KEY=YOUR_SERVER_ONLY_KEY
IMAGE_MODEL=gpt-image-2
TTS_MODEL=gpt-4o-mini-tts
PORT=4173
```

`server.js`가 로컬에서 [OpenAI 이미지 생성 API](https://developers.openai.com/api/docs/guides/image-generation)와 [음성 합성 API](https://developers.openai.com/api/docs/guides/text-to-speech)를 호출합니다. API는 별도 과금되며 OpenAI 계정/조직의 모델 접근권한이 필요합니다. 키는 브라우저로 전달되지 않습니다. 현재 서버는 **127.0.0.1에만 바인딩**됩니다. 인터넷 공개 배포 시 인증·사용량 제한·로깅·비용 상한·HTTPS·CSRF 보호를 추가해야 합니다.

### 기본 모드와 한계

| 기능 | API 키 없이 | API 키 있으면 |
|---|---|---|
| 시어·분위기 분석 | 사전 기반 휴리스틱 | 동일(언어모델 전문 비평 아님) |
| 수채화 시화 | Canvas의 직접 그린 수채풍 일러스트 | 생성 모델의 고품질 수채화 이미지 요청 가능 |
| 맞춤 작곡 | Web Audio 합성, 분위기별 선율·화성 | 동일(외부 전문 작곡 API 아님) |
| 시낭송 | 브라우저 SpeechSynthesis, OS 지원에 따름 | AI 한국어 음성 MP3 생성 가능 |
| 음성 포함 녹화 | 업로드/마이크로 확보한 녹음 음원만 포함 가능 | AI 생성 MP3를 영상 음성에 포함 가능 |

**브라우저 SpeechSynthesis 음성은 표준 Web Audio/MediaRecorder로 직접 캡처할 수 없습니다.** 따라서 브라우저 TTS로 보기만 할 때는 영상 녹화 버튼에서 음성 파일 준비를 안내합니다. 입력한 음성 파일이나 서버 AI 음성은 `MediaElementAudioSourceNode → Web Audio → MediaStreamDestination`을 통과시켜 **배경음악과 함께 실제 녹음**합니다. 음악 덕킹도 이 경로에서 작동합니다.

- 영상은 1280×720/30fps **실시간 WebM**이며 브라우저 인코더/코덱 지원에 따라 실패할 수 있습니다. 오디오/동영상 품질은 브라우저 성능과 입력 음성의 상태에 좌우됩니다.
- 낭송 구절의 위치는 오디오 길이에 비례한 전체 스크롤로 표시됩니다. 단어 단위 음성 정렬은 없으므로 구절 사이 완벽한 타임코드 정합은 보장하지 않습니다.
- 기본 음악은 브라우저 합성악기로 연주되는 시 분위기 기반 창작입니다. 고품질 샘플 기반 상업 작곡/가창 출력과 동일하지 않습니다.
- 본문·악곡 분석은 사전 기반 제안이므로 시의 철학적 의미, 역설, 중의성까지 자동 평가하지 못합니다.
- 녹화 영상의 저작권·음성·그림 권리를 확인하고 본인 창작물 또는 사용 허락된 자료만 사용하세요.

## 테스트

```bash
npm test
```

서버 정상 반환, 시 분석, 소스 구문 검사, UI 이벤트/재생 동작은 자동/브라우저 점검 가능합니다. 실제 음악 출력·마이크/영상 다운로드는 사용자의 브라우저/권한 설정에서 최종 확인해야 합니다.

## 구조

- `index.html` 인터페이스
- `styles.css` 시네마 작업공간
- `src/analysis.js` 시어 분석·수채화 프롬프트
- `src/art.js` 수채화 렌더러·타이포 스크롤
- `src/music.js` Web Audio 오리지널 기악 작곡 및 오디오 믹싱
- `src/main.js` 전체 흐름·재생/일시정지·음성 및 WebM 녹화
- `server.js` 정적 서버·보안된 선택적 외부 API 프록시
- `test/analysis.test.js` 기본 회귀테스트
