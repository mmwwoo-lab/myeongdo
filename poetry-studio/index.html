03

시 낭송 · 음악과 자막 영상

시 낭송은 한국어 음성으로 시를 읽으며 자막을 실제 낭송에 맞춰 스크롤합니다. 음악 만들기는 작곡만 수행하고, 음악 영상 감상은 배경음악과 자막만 재생합니다. 읽는 문장은 화면 중앙에서 금빛으로 강조됩니다.

※ 브라우저 기본 음성 읽기는 감상 기능입니다. 별도 오디오 파일 저장은 외부 TTS API 연동이 있어야 완전하게 지원됩니다.
