# 시의 빛 — 인상파 시화실

시를 입력하면 1920×1080(16:9) 인상파풍 풍경과 한글 붓글씨를 Canvas로 그리는 독립 JavaScript 앱입니다. 외부 AI 호출, API 키, 패키지 설치가 필요 없습니다. 그림은 시의 키워드로 계절·풍경을 선택해 절차적으로 그리며, 시의 모든 의미를 해석하는 AI 이미지 생성은 아닙니다.

저장소 루트에서 `python3 -m http.server 8000 --bind 127.0.0.1`을 실행하고 `/impression-poetry/` 경로를 여세요. 제목·이름·시를 입력한 후 **시화 그리기**를 누릅니다. 풍경 및 글씨 위치를 선택할 수 있고, **다른 붓결**로 새 구도를 그리며 **PNG 저장**으로 원본 해상도 이미지를 받습니다. 글씨는 길이에 맞게 줄바꿈·축소하며, 너무 많은 줄은 입력을 줄이도록 안내합니다. 입력한 시는 서버로 전송하거나 저장하지 않습니다.

폰트: Google Fonts의 Nanum Brush Script(나눔손글씨 붓체), SIL Open Font License. 라이선스는 `fonts/OFL.txt`에 포함되어 있습니다. 폰트도 로컬에서 제공하므로 실행 중 외부 네트워크에 의존하지 않습니다.
