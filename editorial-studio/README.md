# 명도재 시사컬럼 · API 키 없는 신문 특집호 스튜디오

**기사 원문·기사 URL → 기사 핵심 정리 → 약 600자 칼럼 초안 → 한국어 음성 읽기 → 기사 기반 시사만평 → 신문 지면 PNG 저장** 순서로 사용하는 웹형 편집실입니다.

## 제공 기능

- 기사 글을 직접 붙여 넣거나 HTTPS 기사 주소에서 본문 가져오기. 언론사 로그인·유료벽·자동수집 차단은 우회하지 않습니다.
- 기사에 나온 문장 3개를 **'기사 핵심 정리'** 영역에 추출하고, 기사에 실린 내용과 평론가의 해석을 구분하는 독립 시사 칼럼 초안을 **약 600자**로 작성합니다.
- 칼럼은 기사 핵심 내용을 짧게 인용하고 정책 분야별 검증 기준과 제언을 추가하는 **규칙 기반 초안**입니다. 대규모 언어모델을 호출하는 심층 AI 분석이나 추가 사실 검증은 아닙니다.
- 오른쪽 미리보기의 **위쪽 원문 기사 / 아래쪽 칼럼 / 기사 기반 만평** 신문 특집호 지면.
- 칼럼 읽기, 일시정지, 이어읽기, 정지, 한국어 TTS 음성, 현재 낭독 중 문장 강조. 브라우저와 운영체제에 한국어 음성 데이터가 있어야 합니다.
- **API 키 없이** 다섯 가지 만평 연출 유형에 따른 독창적인 브라우저 벡터 시안 생성.
- 신문 지면 PNG 저장, 만평 PNG 저장, 칼럼 복사.

## 설치/실행

Node.js 20 이상 환경에서 이 프로젝트 폴더에서 실행합니다.

```sh
npm start
```

`http://localhost:4176`에서 실행됩니다. 기본 포트가 사용 중이면 `PORT=4188 npm start`로 다른 포트를 지정하세요.

```sh
npm test
```

서버의 `/api/column`는 **외부 유료 AI API를 호출하지 않습니다.** 단순 규칙형 초안 생성이므로 기사 원문 확인·반론 확인 및 최종 문장은 편집자가 수정해야 합니다. `/api/import`는 기사 링크 본문을 수집하기 위해 해당 공개 기사 웹사이트에 HTTPS로 접근할 수 있습니다. 페이지 구조가 다르거나 접근이 차단되면 기사 본문을 직접 입력하세요.

## 배포

- GitHub: `mmwwoo-lab/myeongdo/editorial-studio/` — 기존 `poetry-studio`와 독립.
- Vercel: `myeongdo-editorial-studio` 프로젝트. 프로젝트 루트를 `editorial-studio`로 설정, `public/` 정적 화면과 `api/` 서버리스 함수를 함께 배포.
- 설정해야 할 API 키 **없음**. 프로젝트에 이전 환경변수가 남아 있어도 초안·만평 생성 과정에는 사용하지 않습니다.
- MP3 저장은 제공하지 않습니다. 사용 기기에 설치된 한국어 음성으로 칼럼을 **재생**하는 기능입니다.

## 책임과 출처

이 편집실은 **명도재의 독립적인 칼럼 초안 작성 도구**이며 영남경제신문이나 특정 언론인과 공식적으로 연계된 서비스가 아닙니다. 기사에 적힌 주장과 사실을 혼동하지 말고, 발행 전 원문과 관계자의 반론, 저작권 및 인용 범위를 확인하세요. 내보내는 신문 이미지에는 기사 원문 중 일부만 포함됩니다. 특정 만화가의 고유 그림체 복제는 제공하지 않으며, 일반적인 연출 구성을 응용한 오리지널 시안입니다.
