# 명도재 시사컬럼 · API 키 없는 뉴스룸 특집호

신문 기사나 HTTPS 링크를 받아 **기사 핵심 정리 → 약 600자 시사 칼럼 초안 → 칼럼 읽기 → 시사만평 → PNG 저장**을 진행하는 웹형 편집실입니다. 기존 시화 스튜디오와 같은 GitHub 저장소의 독립 프로젝트입니다.

## 기능
- 기사 본문 붙여넣기 또는 기사 URL 자동 추출. 언론사 로그인·유료벽·자동수집 차단은 우회하지 않습니다.
- 기사에서 핵심 문장 3개 추출, 분야별 검증 기준을 적용한 독립적인 약 600자 논설 초안 작성. **외부 AI 생성 API 호출 없음.**
- 오른쪽 신문 특집호: 상단 기사 원문, 중단 기사 시사만평, 하단 논설 칼럼.
- 칼럼 읽기·일시정지·이어읽기·정지, 한국어 브라우저 TTS, 현재 읽는 문장 강조.
- 다섯 가지 구성 방식 중 선택하는 기사 기반 원본 벡터 만평. 특정 만화가의 고유 화풍 복제는 하지 않습니다.
- 신문 PNG·만평 PNG 저장, 칼럼 복사.

## 실행
Node.js 20 이상에서 이 폴더에서 `npm start`를 실행한 다음 `http://localhost:4176`에 접속하세요. `npm test`로 기능을 검사합니다.

별도의 API 키는 **설정할 필요가 없습니다**. URL 가져오기 기능은 접속 가능한 공개 웹페이지에 서버에서 HTTPS 요청을 보내므로 페이지 구조에 따라 실패할 수 있습니다. 이런 경우 기사 본문을 직접 입력하세요.

## 품질·권리 고지
키 없는 600자 칼럼은 기사의 문장 일부와 주제별 논설 구조를 조합하는 **규칙 기반 초안**입니다. 대규모 언어모델을 사용한 심층 분석도 아니며 기사 내용의 진위를 검증하지 않습니다. 발행 전에 원문·수치·반론을 확인하고 편집하십시오.

**명도재의 독립 프로그램**입니다. 영남경제신문이나 특정 기자·논설위원의 공식 서비스 또는 대리 기고가 아닙니다. 저작권·인용 범위를 확인하세요. MP3 다운로드를 제공하지 않고, 기기에서 지원하는 한국어 TTS로 칼럼을 읽어줍니다.
