# 명도재 시사컬럼 · AI 미디어아트 스튜디오

신문 기사나 URL을 받아 **출처 표기·기사의 사실/주장 구분·약 600자 독립 논설 칼럼·컬러 신문 이미지·한국어 낭독**을 하나의 편집 화면에서 만드는 웹앱입니다.

## 구성

- `public/index.html`, `public/style.css`, `public/app.js` — 방송국형 편집 화면, 실시간 Canvas 신문 이미지, 칼럼 음성 읽기
- `api/import.js` — 기사 링크 추출 API (HTTPS, DNS/내부망 제한, 리다이렉트 제한, HTML 크기 제한)
- `api/column.js` — 사실을 추가하지 않는 논설 칼럼 작성 API
- `api/voice.js` — API 키가 있는 경우 선택적으로 MP3 낭독 음원 생성
- `lib/article.js` — 공개 기사 HTML 요약 추출
- `lib/column.mjs` — 약 600자 키 없는 기본 초안 + 모델 연동 논설
- `server.js` — 로컬 개발용 Node.js 서버

## 실행

Node.js 20 이상에서 프로젝트 루트에서:

```sh
npm start
```

브라우저에서 `http://127.0.0.1:4176` 접속. API 키 없이도 텍스트 입력 → 기본 논설 초안 → 신문 PNG → 브라우저 TTS 낭독이 가능합니다. 기사 URL 자동 수집은 대상 사이트의 HTML/차단 정책에 따라 달라집니다.

```sh
npm test
```

## 선택적 API 설정

서버 환경변수에 아래 값을 설정하면 AI 논설 작성을 활성화할 수 있습니다. 키는 브라우저 코드나 GitHub에 저장하지 않습니다.

- `OPENAI_API_KEY`: 서버 측 모델/음성 API 키 (미설정 시 기본 초안 모드)
- `OPENAI_MODEL`: 논설 생성용 모델 (예: `gpt-4.1-mini`)
- `OPENAI_TTS_MODEL`: MP3 생성용 모델 (예: `gpt-4o-mini-tts`)
- `PORT`: 로컬 포트, 기본 4176

**MP3 파일**: 서버 음성 API 키가 있어야 생성/다운로드 가능합니다. 기본 브라우저 TTS는 들려줄 수 있지만 녹음 파일로 내보낼 수 없습니다. 한국어 여성 목소리는 설치된 브라우저 음성에 따라 달라질 수 있습니다.

## 칼럼 제작 흐름

1. 기사 주소(HTTPS)를 입력하여 본문을 추출하거나, 본문을 직접 붙여 넣습니다.
2. 제목·출처를 확인합니다.
3. `기사 분석 → 약 600자 논설 작성` 버튼을 누릅니다.
4. 문장과 사실관계를 수정합니다.
5. `칼럼 읽기`로 TTS 음성 감상하고 현재 읽는 문장 강조를 확인합니다.
6. 오른쪽 `신문 칼럼 PNG 저장`으로 이미지 출력, `칼럼 내용 복사`로 텍스트 출력합니다.

## 고지

- 제작자·논설 표기: **명도재 AI 논설**. 이 프로젝트는 영남경제신문 및 김진욱 대표의 공식 서비스, 대리 기고, 음성 복제 도구가 아닙니다.
- 특정 신문사나 기자의 고유 문체를 복제하지 않습니다. 지역경제와 정책을 검증하는 일반 논설 관점을 구현했습니다.
- 게시·공유 전 원문 출처와 사실관계·초상권/저작권·반론을 확인하세요. 언론사의 접근 제한, 이용약관, 저작권을 우회하지 않습니다.
- API 없는 기본 초안은 기사 일부와 범용 검증 질문을 조합하는 **단순 기본 모드**로서 심층 AI 재해석이 아닙니다.
- URL 본문 자동 추출은 브라우저 외부에서 서버로 이루어지며 공개 사이트라도 추출 실패할 수 있습니다. 로그인/유료벽은 우회하지 않습니다.
- 공개 프로덕션에서 대규모 API 요청을 허용하려면 계정별 인증/호출량 제한, 사용료 상한 및 사용 기록을 추가해야 합니다.

## 배포

Vercel 프로젝트 루트를 이 프로젝트 폴더로 설정하고, 프레임워크를 `Other`로 선택합니다. `public/`은 정적 파일이 되고 `api/`는 서버리스 함수가 됩니다. 서버 환경변수는 Vercel 프로젝트 설정에서 지정합니다.
