## 원시 전문 등록 · 2026-10-28

- `authorized-originals.js`: 서지월 46개 지면(산문 「나의 抒情詩」, 제목 이본 「진달래 山川」 포함), 김창영 3편, 김응준 2편, 기존 홍용암 1편. 제공 원고의 표기와 제목을 보존하고 중복은 첫 제공본을 기준으로 편집했습니다. 시집 원전과 독립 대조하지 않았습니다.
- `original-recitals.js`에 그 시를 Create Audio로 낭송한 MP3 원본/미리듣기 정보를 별도로 기록합니다.
- `AUTHORIZED-ORIGINALS-TEMPLATE.json`에는 서지월 60편과 조선족 시인 20편, 총 80개 시의 작성·검수 대기 칸이 있습니다.
- 전편 공개 허락을 받았다는 편집자 확인을 존중하되, 인터넷에서 확인한 텍스트를 원문과 대조하지 않고 임의 재게시하지 않습니다. 받은 원고를 추가하면 전체 홈페이지 구조를 바꾸지 않고 본문 표시가 가능합니다.
- 기사 순서: 시 소개 → 시 원문(등록된 작품만) → 시 원문 낭송(등록된 작품만) → 해설 낭송 → 시 해설.

## 원문과 소리 · 2026-10-28 추가 편집

- `#originals`: 저자별 제공 원고 52개 지면. 기존 작품 소개 60개/20인 지면도 유지하며 조선족 작품은 23편입니다.
- `works/<작품키>/`: JavaScript 없이도 원문을 읽을 수 있는 공유용 정적 지면 52개. 작품별 제목·저자·canonical·Open Graph·Twitter 카드가 HTML에 들어 있습니다.
- `audio-source/`: 전문 낭송 MP3의 작은 원본 조각 및 SHA-256 명세. `node restore-original-audio.cjs`로 52개 완전한 MP3를 `audio-originals/`에 복원합니다. 사용자 승인 후 Microsoft Edge 온라인 음성 합성, SunHi 한국어 여성 음성, 속도 -15%로 제작했습니다. 낭송 대본의 한자는 한글 독음으로 변환하며 웹 원문은 보존합니다. 24kbps/22.05kHz/mono MP3.
- 전문 낭송은 시인 육성이 아닌 AI 합성 음성입니다. 기존 Create Audio 해설 약 30초 미리듣기와 별개입니다.
- `assets/issue-1028-social.png`: 1200×630 소셜 공유 이미지. `sitemap.xml`에 개별 지면을 포함합니다.
- 빌드: `node restore-original-audio.cjs && node prepare-audio.cjs`. 기존 정적 Vercel 구조와 공개 도메인을 유지합니다. 기존 해설 미리듣기 80개는 기존 배포/제공자에서 보존하므로 최초 빌드에는 네트워크가 필요합니다. 새 전문 낭송 52개는 외부 음성 서비스 없이 저장소에서 복원합니다.
