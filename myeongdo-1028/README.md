# 명도재 문예신문 1028 — 서지월 시인 특별호

공개 주소: https://myeongdo-1028.vercel.app/

정적 사이트. Vercel 프로젝트 myeongdo-1028의 소스 디렉터리는 이 폴더입니다.

- 서지월 작품 소개 60개, 중국 조선족 시인 소개 20개.
- audio/의 MP3 80개는 기존 Create Audio 해설의 약 30초 미리듣기입니다. 시 전문 낭송이나 시인의 실제 육성이 아닙니다. 원본 제공자 주소는 audio-previews.js에 보존합니다.
- 원시 전문은 재게시하지 않으며 외부 출처로 연결합니다. 서지월 직접 평문과 편집 해설을 구별합니다.
- 최신작, 아카데미 소속, 사용자 제공 자료의 독립 검증 한계는 해당 지면에 표시합니다.

## 원시 전문 등록 · 2026-10-28

- `authorized-originals.js`는 사용자로부터 실제 전달받은 원문을 각 시의 원문 지면에 넣는 등록 파일입니다. 최초 등록: 홍용암 「기러기」 (사용자 제공 원고).
- `original-recitals.js`에 그 시를 Create Audio로 낭송한 MP3 원본/미리듣기 정보를 별도로 기록합니다.
- `AUTHORIZED-ORIGINALS-TEMPLATE.json`에는 서지월 60편과 조선족 시인 20편, 총 80개 시의 작성·검수 대기 칸이 있습니다.
- 전편 공개 허락을 받았다는 편집자 확인을 존중하되, 인터넷에서 확인한 텍스트를 원문과 대조하지 않고 임의 재게시하지 않습니다. 받은 원고를 추가하면 전체 홈페이지 구조를 바꾸지 않고 본문 표시가 가능합니다.
- 기사 순서: 시 소개 → 시 원문(등록된 작품만) → 시 원문 낭송(등록된 작품만) → 해설 낭송 → 시 해설.
