# 명도재 어린이 과학게임

명도재 이명우의 어린이 과학게임 시리즈 공식 자료 보관 폴더입니다.

## 공개 통합 홈페이지
https://myeongdo-kids-science-mmwwoo-6434.vercel.app/

## 현재 시리즈
- 제01호 [태양계 우주탐험대](https://myeongdo-kids-science-space-mmwwoo-6434.vercel.app/)
- 제02호 [인체 속 탐험대](https://myeongdo-kids-science-body-mmwwoo-6434.vercel.app/)
- 제03호 [어린이 기상예보관](https://myeongdo-kids-science-weather-mmwwoo-6434.vercel.app/)
- 제04호 [꼬마 과학자의 실험실](https://myeongdo-kids-science-lab-mmwwoo-6434.vercel.app/)

## 새 시리즈 추가
1. 새 게임을 별도 Vercel 프로젝트에 배포합니다.
2. 이 폴더의 games.json에 번호, 제목, 설명, 게임 주소를 추가합니다.
3. 통합 홈페이지의 games.json에도 같은 항목을 반영하고 재배포합니다.

※ 현재 통합 홈페이지는 독립 Vercel 프로젝트로 배포되어 있으며 GitHub 저장소와 자동 동기화되지는 않습니다.
