## 사용 방법

모든 파일을 같은 디렉터리에 둔 채 `index.html`을 열거나 정적 웹 호스팅의 공개 폴더에 그대로 올리세요. 영상관의 언어 버튼은 해당 언어의 MP4를 재생합니다. 배포 시 MP4 및 MP3 파일을 누락하면 재생되지 않습니다.

## 공개 시 주의

영상과 음악의 게시 권한 및 초상권·저작권을 확인하세요. GitHub의 100MB 단일 파일 제한에는 걸리지 않지만 저장소 전체와 브라우저 로딩 용량이 큽니다. 대용량 전송에는 객체 스토리지/CDN을 권장합니다.
