# 명도재 시사컬럼 · 방송국형 신문 특집호 웹사이트

독립 웹 프로그램으로, 기존 `poetry-studio`를 변경하지 않습니다.

## 핵심 기능

1. 기사 URL(HTTPS) **또는** 기사 본문을 입력합니다. 본문 입력란에는 `제목:`, `출처:`, `내용:`을 함께 적거나 일반 텍스트만 넣어도 됩니다.
2. **기사 정리 · 600자 칼럼 작성** 버튼으로 기사 원문과 요약을 신문 지면에 표시하고 규칙 기반의 약 600자 독립 논설 초안을 작성합니다.
3. 5개 일반 연출 방식(고전 4컷·현장 인물·상징 은유·인물 대사·연속 풍자)에서 기사의 주제를 바탕으로 독창적인 **벡터 시사만평**을 제작할 수 있습니다. 특정 작가의 고유 화풍을 복제하지 않습니다.
4. 칼럼 아래 **읽기·일시정지·이어읽기·정지** 버튼으로 브라우저 한국어 TTS 낭독을 제어합니다. 이 기능은 별도의 MP3 파일을 생성하지 않습니다.
5. 신문 지면과 만평 PNG 저장, 복사, 인쇄·PDF 저장을 지원합니다.

화면은 검정·은회색 방송국형 편집실 콘솔(좌측)과 흰색 신문 특집호(우측)를 사용합니다.

## 실행

Node.js 20 이상에서 `npm start`를 실행하고 `http://localhost:4176/`에 접속합니다. 자동 테스트는 `npm test`입니다.

## 편집·저작권 및 정확성 안내

기사 원문은 입력자의 편집 화면에서 확인하는 용도입니다. 신문 지면을 외부 공개할 때는 저작권·인용 범위를 검토하세요. 칼럼은 추가 취재와 팩트체크를 대체하지 않는 초안이며, 기사 속 주장과 검증된 사실을 구분해 최종 편집해야 합니다. 이 서비스는 특정 언론사 또는 특정 언론인의 공식 서비스가 아닙니다.
