# 명도재 한국미술 거장 30인 가상미술관 — 전시 자료

- 전시명: 한국미술 100년, 거장 30인의 빛
- 작가: 30인
- 전시관: [gallery/index.html](../index.html)
- 데이터: [artists.json](./artists.json)
- 기획: 명도재 AI 문화예술기업

## 자료 구성

각 작가별 전시 순서, 이름, 분류, 핵심 주제, 작품 세계 소개, 큐레이터 해설 초안, 감상 질문, 이미지 권리 확인 상태를 담았습니다.

## 사용 안내

전시 순서는 공신력 있는 인기 순위나 경매가 순위가 아닙니다. 순위 표기는 기획상의 순서로만 사용하세요.
실제 대표작 사진, 작가 얼굴 사진, 작품 제목 및 소장처 정보는 아직 검증 및 업로드되지 않았습니다. 이미지 등록 전에 권리자·소장기관의 허락과 출처·이용 조건을 확인하세요.

## 추가 자료 등록 권장 구조

- gallery/assets/works/ : 이용 허락된 작품 이미지
- gallery/assets/portraits/ : 이용 허락된 작가 사진
- gallery/assets/audio/ : 도슨트 음원
- gallery/data/artists.json : 현재 등록한 작가 30인 설명 자료

## 작성 기준

전시 해설은 신규 작성한 소개 문안이며 작가의 공식 입장 또는 미술관의 인증 설명을 의미하지 않습니다.
